# 01 要件・対象範囲

現行仕様と対象範囲を定義する。受け入れ条件は[07](07-validation-and-plan.md)、公開前の確認事項は[リリース手順](release.md)を参照。

## 目的

オンラインの辞書ファイルを「ソース」として登録し、取得済みの単語を閲覧する。対応端末では有効なソースの内容を共有ユーザー辞書（UserDictionary）へ一方向に同期する。

メイン画面はソース一覧。ナビゲーションタブは「ソース一覧」「設定」の2つとする。同期状況を独立したタブにしない。

## 機能要件

| ID | 要件 |
|---|---|
| UI-01 | 起動時にソース一覧を表示する（初回起動だけ先にセットアップを表示）。未登録時も同じ画面から追加できる |
| UI-02 | ナビゲーションは「ソース一覧」「設定」の2項目 |
| SRC-01 | オンラインの辞書ファイルを複数登録できる。追加時の必須入力は名前・URLのみ |
| SRC-02 | 形式・言語・文字コードの初期値はすべて「自動」。自動同期の間隔は24時間。すべて後からソース単位で編集できる |
| SRC-03 | 追加操作で初回取得・解析・保存を行う。成功した場合だけソース一覧へ追加する。失敗時は入力値を保持した直前の追加画面へ戻る |
| SRC-04 | 各ソースに名前、最終更新日時、自動同期の間隔、件数、有効／無効トグルを表示する |
| SRC-05 | 最終更新から24時間以内は「n時間前」、それ以外は日時を表示する。境界・時刻の意味は03に定義する |
| SRC-06 | ソースごとに有効／無効を切り替えられる。初期値は有効。無効でも設定と取得済み単語を保持する |
| SRC-07 | 複数選択して一括で有効化・無効化・削除できる。個別処理と同じ規則を使う |
| SRC-08 | 名前・URL・各オプションを編集できる。取得に関わる設定の変更は、新しい条件で取得が成功するまで旧設定と旧データを維持する |
| VIEW-01 | 通常状態でソースをタップすると、そのソースの取得済み単語一覧を表示する |
| VIEW-02 | 単語一覧は閲覧のみ。単語・読みの検索は可能だが、単語の追加・編集・削除・個別除外は設けない。オフラインでも閲覧できる |
| SYNC-01 | 有効なソースを指定間隔で自動同期する。手動同期も可能。OSや通信状態による遅延を許容する |
| SYNC-02 | 取得・解析失敗時は前回の正常データを保持する。複数ソース中の1件の失敗で他の成功を取り消さない |
| SYNC-03 | 既存の手動登録語・他アプリの語を上書きしない。削除するのは、ソースを無効化・削除したときにそのソースの語と完全に一致する既存語だけ。同じ内容の再同期で重複を増やさない |

## 追加・編集の項目

| 項目 | 必須 | 初期値 | 扱い |
|---|---|---|---|
| 名前 | 必須 | 空欄 | 一覧での表示名。重複名は許可 |
| URL | 必須 | 空欄 | 公開辞書ファイルを直接取得できるHTTPS URL |
| 形式 | 任意 | 自動 | 対応形式から手動指定も可能。範囲は02 |
| 言語 | 任意 | 自動 | 下記の規則で解決。手動指定も可能 |
| 文字コード | 任意 | 自動 | 対応文字コードから手動指定も可能。範囲は02 |
| 自動同期の間隔 | 任意 | 24時間 | ソース別に選択。初期の選択肢は1・6・12・24時間・3日・7日とする［設計判断］ |

任意項目を操作せず、名前とURLだけで追加できる。間隔は選択式とし、自由入力による複雑な検証を設けない。ソースの有効／無効は一覧のトグルで扱い、別の「自動取得ON/OFF」を重ねない。

## 言語の「自動」

［設計判断］ファイルに対応済みの言語情報があればそれを使用し、ない場合は現在の対象辞書に合わせて日本語（`ja`）を使用する。現在の対応形式で言語情報を持つのはGboard形式の言語タグだけで、単語ごとにそれを使う（1ファイルに複数言語が混在してよい）。それ以外の形式の自動の解決結果は日本語になる。文字列からの言語推測や外部サービスは追加しない。

選択値「自動」と解決値「日本語」を分けて保存・表示する。手動指定を優先し、端末のUI言語変更で既存ソースの言語を変えない。「すべての言語」を選んだ場合のみProviderの`locale=NULL`に対応させる。

## 同期と有効／無効

［設計判断］「自動同期」は取得・解析と、対応端末での共有ユーザー辞書への差分反映を含む。通常の更新で毎回差分承認を要求しない。

有効なソースだけを定期同期と共有辞書への反映対象にする。無効化すると定期同期を止め、そのソースの共有辞書への参照を外す。他の有効ソースが必要とする語は残し、そのソースの語と完全に一致する既存語（手動登録・他アプリの語）は削除する。保存済み単語は引き続き閲覧できる。再有効化では保存済みの正常データを反映し、取得期限を過ぎていれば再取得する。無効化で共有辞書から外す範囲は05に定義する。

初回追加の成功条件は取得・解析・ローカル保存の成功。端末の同期対応診断を追加の必須条件にしない。共有辞書に未反映なら「未反映」、反映に失敗したら「同期失敗」を別に表示する。

## 最小限の検証と対象範囲

- 入力は名前・URLの空欄と、標準URLパーサーでのHTTPS URLの解釈を確認する。名前100文字・URL8,192文字など独自のフォーム上限は必須仕様にしない。
- URLのクエリは順序・重複・エスケープを保持する。前後の空白は除去し、フラグメントは取得に使わない。ユーザーにURLの再入力を要求するためだけの検証はしない。
- TLS検証、通信タイムアウト、取得容量上限、対応形式での解析は維持する。HTMLや壊れた辞書を空の成功結果に置き換えない。
- 正常な空辞書は0件として扱う。空・削除率・削除件数だけを理由に多段階の承認フローを設けない。ソース削除の確認は1回とする。
- 同じ取得URLの二重登録は既存ソースを案内する。別URLの内容一致を登録拒否の理由にしない。
- 対象は公開HTTPSファイル、02に記載した形式・文字コード。認証、配布ページからのリンク抽出、書庫展開、任意CSVの列推測は対象外。URL内の認証情報も扱わない。
- 単語の手動編集、オンラインへの書き戻し、アカウント、独自バックエンドは対象外。

既存のWi-Fiのみ設定、日本語UI、Material 3 Expressive、画面幅・回転への対応は維持する。レアケースの網羅、独自の言語推測、複雑な自動補償は対象外とする。

## 端末対応

キーボードとして有効化する方式は採用可能。入力内容を読み取り・保存・送信しない。SM-F971Z / Android 17 / GboardWu・かなフリックで小規模に確認済みだが、他端末へ一般化しない。

root・ADB権限付与・Shizuku・隠しAPIを通常利用に要求しない。非対応端末でも取得・閲覧を利用できるが、共有辞書への同期成功とは表示しない。
